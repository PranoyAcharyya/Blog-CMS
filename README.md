🚀 Project Name

A modern full-stack web application built with Next.js App Router, shadcn/ui, and Supabase, featuring authentication, form validation, animations, and a clean responsive UI.

⚡ This project focuses on real-world architecture, best practices, and production-ready patterns.

✨ Features

✅ Authentication (Email / Password)

✅ Protected Routes

✅ Modern UI with shadcn/ui

✅ Forms with React Hook Form + Yup/Zod

✅ Server & Client Components

✅ Clean Folder Structure

✅ Reusable UI Components

✅ Dark / Light Mode

🛠 Tech Stack

Frontend

Next.js (App Router)
